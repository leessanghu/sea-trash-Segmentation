2026 국립공원 위성 모니터링 AI 챌린지 **주제 4(해안 쓰레기 탐지 및 규모 추정)** 참가작입니다.

| | |
|---|---|
| 최종 순위 | **138팀 중 29위** |
| Public 점수 | **0.7195** (1위 0.88) |
| 평가 방식 | 추론 자동화 — 모델과 실행 코드를 제출하면 운영측이 비공개 평가셋으로 채점 |
| 제출 구성 | 6개 모델 앙상블 (CNN 2 + ViT 4), TTA 8, 고정 후처리 |

## 1. 문제

**입력** 0.3 m/px RGB 위성영상 256×256 패치. **출력** 쓰레기 구역의 이진 마스크(RLE).

**평가 지표**

```
최종 점수 = 0.5 × macro F1  +  0.5 × 형상 점수
```

- **macro F1 (패치 존재 판정)** — 예측 마스크의 1인 화소가 **50개 이상**이면 그 패치를 양성으로 예측한 것으로 본다. 양성·음성 클래스의 F1을 각각 구해 평균한다.
- **형상 점수 (범위 예측)** — 정답에 쓰레기가 있는 패치마다, 경계에서 **1화소 이내의 어긋남은 맞은 것으로 치고** 정밀도·재현율의 조화평균을 구한다. 양성 예측을 내지 않은 패치는 0점.

지표가 두 층으로 나뉜 것이 설계의 핵심 제약이었다. **"있다/없다"를 맞히는 능력과 "어디까지인지"를 그리는 능력이 따로 채점**되고, 두 능력을 잘하는 모델이 서로 달랐다.

## 2. 가장 큰 난점 — 학습 데이터와 평가 데이터의 플랫폼이 다르다

대회는 학습 데이터를 제공하지 않았다. 운영측이 참고 자료로 안내한 AIHub 「국립공원 변화탐지」 데이터셋에서 **해안쓰레기 라벨은 드론 0.1 m 영상에만** 있었고, 운영측도 "촬영 플랫폼과 해상도가 크게 달라 해상도가 일치하는 학습 자료로 보지 말 것"을 명시했다.

| | 학습에 쓸 수 있는 것 | 평가 대상 |
|---|---|---|
| 플랫폼 | 드론 | 위성 |
| 해상도 | 0.1 m | 0.3 m |
| 선명도 | 또렷함 | 센서 MTF로 흐릿함 |
| 지역 | 태안 한 곳 위주 | 비공개 (국립공원 해안) |

이 차이 때문에 **로컬 검증 점수가 리더보드를 예측하지 못했다.** 이 저장소에서 가장 값어치 있는 기록은 모델 구조가 아니라 그 어긋남을 다룬 방식이다(6번 항목).

## 4. 모델

같은 데이터로 학습한 **서로 다른 구조 6개의 예측 확률을 평균**한다. 모든 멤버에 D4 대칭 TTA 8가지를 적용한다.

| # | 구조 | 입력 처리 | 비고 |
|---|---|---|---|
| 0 | UNet + ResNet18 | 256 → 512 (2배 확대) | 하드 네거티브 이어학습 |
| 1 | UNet + ConvNeXt-T | 256 → 512 | |
| 2 | DINOv2 ViT-S/14 + 다층 디코더 | 448 | 하드 네거티브 이어학습 |
| 3 | DINOv3 ViT-S/16 + 다층 디코더 | 448 | |
| 4 | DINOv3 ViT-S/16 + **LoRA** (r=16) | 448 | 백본 동결, 저랭크 보정만 학습 |
| 5 | DINOv2 ViT-S/14 + **DoRA** (r=16) | 448 | 〃 |

**설계 의도**

- **입력을 2배로 키운 CNN** — 쓰레기 덩어리는 0.3 m에서 몇 화소에 불과하다. 2배로 키워 넣으면 유효 해상도가 올라간다.
- **ViT는 중간층 4개(2, 5, 8, 11)를 뽑아** 융합한다. 마지막 층만 쓰면 위치 정보가 뭉개진다.
- **LoRA/DoRA 멤버** — 사전학습 특징을 최대한 보존해 드론→위성 차이에 덜 흔들리게 하고, 전체 미세조정 멤버와 다르게 틀리도록 다양성을 확보한다. 저장할 때 보정을 본 가중치에 합치므로 추론 코드는 일반 모델과 같다.
- **CNN과 ViT를 섞은 이유** — 리더보드에서 확인한 바로는 **CNN 비중이 판정(F1)을, ViT가 형상을** 끌어올렸다. 둘 중 하나로 몰면 점수가 떨어졌다.

### 하드 네거티브 마이닝 (HNM)

실패 분석에서 가장 큰 손실원이 **"쓰레기가 없는데 있다고 확신하는 패치"**였다(음성 795장 중 77장).

1. 기존 6멤버로 음성 학습 패치 1,855장을 추론한다.
2. 확신도가 높은 오탐 **400장**을 뽑아 별도 묶음으로 만든다.
3. 그 묶음을 15% 비중으로 섞어 **2에폭 × 200스텝, 학습률 0.3배**로 짧게 이어학습한다.
4. 좋아진 멤버만 교체한다.

ResNet18과 DINOv2 멤버를 교체했을 때 **0.7079 → 0.7195 (+0.0116)**로 올랐다. 이 저장소의 최종 가중치가 그 결과물이다.

## 5. 추론과 후처리

```python
# 1) 6멤버 × TTA8 평균 → 확률맵 prob(256×256), 분류헤드 확률 cls
# 2) 패치 판정
판정점수 = 0.25 × cls + 0.75 × (확률 상위 50화소의 평균)
if 판정점수 < 0.40:  → 빈 예측
# 3) 마스크
mask = prob > 0.5
mask = 10화소 미만 연결요소 제거
if mask.sum() < 50:  → 확률 상위 80화소로 채움   # 판정이 양성이면 반드시 50px 이상 남긴다
mask = 3×3 팽창(dilate 1)
```

고정 설정: `t_pix 0.5 / t_img 0.4 / alpha 0.25 / min_cc 10 / rescue_px 80 / dilate 1`

**후처리 각 항목의 근거**

- **판정과 마스크의 임계값을 분리** — 양성 패치를 놓치면 F1과 형상에서 모두 0점이라, 오탐보다 손실이 3~5배 크다. 그래서 판정은 느슨하게(0.40), 마스크는 보수적으로(0.50) 잡는다.
- **`rescue_px 80`** — 판정은 양성인데 마스크가 50화소 미만이면 그 패치는 규칙상 빈 예측이 되어 양쪽에서 감점된다. 확률 상위 80화소로 채워 그 상황을 막는다.
- **`dilate 1`** — 평가가 1화소 어긋남을 봐주므로 **1화소 팽창은 정밀도 손실 없이 재현율만 올린다.** 실제로 리더보드 +0.002.

## 6. 검증 전략과 실패 기록

이 대회에서 가장 많은 시간을 쓴 부분이다. **로컬 검증셋(드론, 태안 한 곳)이 리더보드와 반복해서 어긋났다.**

### 리더보드 전체 기록

| 제출 | 구성 | Public | 로컬 예측 | 결과 |
|---|---|---|---|---|
| v4 후처리 | | 0.6596 | | |
| v5 + 검증셋으로 튜닝한 후처리 | `tune.py`로 로컬 최적화 | **0.6418** | 로컬 최고 (0.8223) | ❌ 로컬 최적이 LB 최저 |
| v5 + 고정 후처리, dilate 0 | | 0.7059 | | |
| v5 + 고정 후처리, dilate 1 | | 0.7079 | | ✅ 기준 |
| hnm-a | ConvNeXt 포함 3멤버 교체 | 0.7073 | +0.0094 | ❌ |
| **hnm-b** | ResNet18·DINOv2 교체 | **0.7195** | +0.0071 | ✅ **최종** |
| cnxt 제거 | 로컬 단독 꼴찌 멤버를 뺌 (5멤버) | 0.6978 | +0.0064 | ❌ **−0.022** |
| 12멤버 확장 | 새로 학습한 ViT 위주 6멤버 추가 | 0.7077 | +0.0118 | ❌ |

### 여기서 얻은 것

1. **후처리가 모델보다 컸다.** 똑같은 가중치로 후처리만 바꿔 0.6418 ↔ 0.7079, 차이가 **0.066**이었다. 모델 교체로 얻은 최대폭(+0.0116)의 5배가 넘는다.

2. **분포가 다른 검증셋으로 후처리를 튜닝하면 안 된다.** 로컬에서 최적인 설정이 리더보드에서는 최악이었다. 이후 후처리를 고정하고 다시 건드리지 않았다. 이 현상은 Ovadia et al. (NeurIPS 2019)의 "i.i.d. 검증셋으로 사후 보정을 하면 분포 이동 상황의 보정이 오히려 나빠진다"는 결과와 일치한다.

3. **앙상블 멤버를 로컬 점수로 빼면 안 된다.** 로컬 단독 성능이 꼴찌였던 ConvNeXt를 뺐더니 로컬은 +0.006인데 리더보드는 **−0.022**였다. 그 멤버는 **로컬에서 약했던 게 아니라 "형상"에서 약했을 뿐**이고, 위성 테스트에서는 판정을 지탱하고 있었다. 사전학습 방식이 다른 CNN과 ViT는 "로컬 점수 ↔ 테스트 점수" 관계가 서로 다른 선 위에 있어서, 로컬 점수로 두 계열을 비교하는 것 자체가 성립하지 않는다 (Miller et al., ICML 2021; Andreassen et al., TMLR 2022).

4. **판정과 형상은 서로 다른 모델이 잘한다.** 앙상블에서 CNN 비중을 올리면 F1은 0.924→0.949로 오르고 형상은 0.640→0.610으로 떨어졌다. 총점에서는 두 효과가 상쇄돼 보이지 않았다. 리더보드 5개 제출의 점수는 **판정 앙상블의 CNN 비중**과 같은 방향으로 움직였다.

5. **그래서 마지막에 쓴 구조** — 한 번의 추론으로 확률을 두 번 평균해, **판정은 CNN 비중을 높인 앙상블로, 마스크는 검증된 앙상블로** 그린다 (`predict_probs_dual`, `postprocess_dual`). 판정 가중치를 그대로 두면 패치 판정이 기존 제출과 100% 같아서 F1은 고정되고 형상만 바뀐다. 같은 발상이 SIIM-ACR Pneumothorax 대회 1위 솔루션에도 쓰였다(판정용 높은 임계값 + 마스크용 낮은 임계값).
